# Programming Foundations Roadmap

This repository shows my learning journey in programming. After one
year of practice, I finished the foundation stage, which helped me 
understand core programming concepts.

I believe that a strong foundation is the key to learning fast. The more
you understand the basics, the easier it is to learn new technologies
in the future.

This repository contains my code and exercises and projects from 
this year. I chose **C++** as my main language because it is strong
 and powerful.

 ## 📚 Repository Contents
This repository includes projects, exercises, and problem-solving 
solutions built step by step:
* **Programming Fundamentals & Logical Thinking:**
* Basic concepts, variables, and conditions (Control Flow).
* Building logical thinking through algorithmic thinking and problem 
decomposition.
* Loops, Arrays, and Matrices.
* Functions and modular code.

* **Problem Solving & Algorithms:**
  * Practical solutions to programming problems and logic challenges.
  * Searching and Sorting algorithms.
  * Basic Data Structures (Linked Lists, Stacks, and Queues).

* **Object-Oriented Programming (OOP):**
  * Classes and Objects.
  * Encapsulation, Inheritance, and Polymorphism.
  * Building structured systems and simulations.
 
* **Practical Projects:**
  * Rock-Paper-Scissors Game.
  * Full Banking System.
  * ATM System Simulation.
  * Custom Date Manipulation Library.
  * Logic-building exercises and problem-solving tasks.
